# Selenium Case Automation Tool

## Project

This project is a Python-based automation script built using Selenium to streamline repetitive case processing tasks.  
It reads case IDs from an Excel file, performs automated actions in a browser, and logs the results efficiently.

>  Note: All sensitive information (such as URLs and credentials) has been intentionally removed for security and compliance.

---

##  To Add this Features

- 1. Bulk processing of case IDs from Excel  
- 2. Automated browser actions using Selenium  
- 3. Dropdown selection and comment submission  
- 4. Logging system for tracking execution  
- 5. Failed cases captured separately  
- 6. Auto browser restart for better stability  
- 7. Optional Chrome profile support 

---

## Use Tech Stack

- **Python 3.x**
- **Selenium**
- **Pandas**
- **WebDriver Manager**
